# Aquarium HTML

브라우저에서 실행하는 수족관 프로젝트입니다. macOS용 데스크톱 수족관 프로젝트 [Deskworlds](https://github.com/chaseleantj/deskworlds)를 바탕으로 HTML 버전으로 제작했습니다.

## 실행하기

- [웹에서 수족관 열기](https://jyha84.github.io/Aquarium-HTML/)
- 저장소의 `index.html`을 브라우저에서 열어 실행할 수 있습니다.
